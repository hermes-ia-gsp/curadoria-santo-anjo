Convenções de publicação

Estrutura recomendada para permitir novos agentes e escolas sem quebrar links existentes.

Pastas principais

  • / — curadoria atual do Santo Anjo. Não transformar em hub sem decisão explícita.
  • /arquivo/YYYY-MM-DD/ — curadorias arquivadas por data.
  • /processo-agentes/ — fluxo Tico + Teco.
  • /hub/ — índice geral para futuras publicações.
  • /escolas/ — índice/reserva para futuras escolas.
  • /agentes/ — índice/reserva para materiais de agentes.
  • /assets/shared/ — recursos compartilhados.
  • /templates/ — modelos-base documentados.

Regras

  • Cada agente ou escola nova deve publicar em pasta própria.
  • Não sobrescrever index.html da raiz sem confirmar, porque ele é a curadoria atual.
  • Links de histórico devem ser absolutos a partir de /curadoria-santo-anjo/....
  • Commits devem indicar escola, agente e data quando possível.
