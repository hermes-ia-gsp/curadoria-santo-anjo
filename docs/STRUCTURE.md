# Estrutura de publicação

Este repositório pode funcionar como hub de publicações dos agentes, mantendo os links atuais do Santo Anjo.

## Convenções

- `/` — curadoria atual do Colégio Santo Anjo.
- `/arquivo/YYYY-MM-DD/` — arquivo das curadorias por data.
- `/arquivo/` — índice do histórico.
- `/processo-agentes/` — página viva do fluxo Tico + Teco.
- `/hub/` — hub geral de publicações.
- `/escolas/` — índice/reserva para futuras escolas.
- `/agentes/` — índice/reserva para agentes.
- `/assets/shared/` — recursos compartilhados.
- `/templates/` — modelos-base e notas.

## Regras para futuros agentes

1. Publicar em pasta própria.
2. Não sobrescrever a home sem autorização.
3. Usar links absolutos com prefixo `/curadoria-santo-anjo/`.
4. Manter histórico por data quando houver recorrência.
5. Fazer commits com escopo claro.
